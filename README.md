# 当日受付ボード

公演ポータル (ls-portal) の「入場管理 → 🖥 受付ボード」から開く、受付用のボードです。

- 中身は ls-portal の `Board.html` / `CheckinBoardCss.html` / `CheckinBoardCore.html` から `tools/build-board-pages.mjs` で作ります。ここを直接直さないでください。
- 公演ポータルの URL とキーは、開く URL の `#` の後ろで受け取ります。このリポジトリには書きません。
- 全画面で使えます。タブレットでは「ホーム画面に追加」すると、アプリのように開けます。
